# Climate Scenario Definitions

This directory contains predefined climate scenario configurations in JSON format.

## Usage

Scenario JSON files define parameters for cost calculations:
- CO2 price trajectories
- Temperature pathways
- Policy stringency levels
- Physical climate impact levels

## Format

See `specs/001-esrs-e1-simulation/quickstart.md` for JSON schema example.

## Predefined Scenarios

(To be added during implementation):
- `iea_nz2050.json` - IEA Net Zero by 2050
- `ngfs_current_policies.json` - NGFS Current Policies
- `ngfs_net_zero.json` - NGFS Net Zero 2050
- Custom scenarios can be added following the schema
